# Tettyrs

OCR and document processing solutions for automated data extraction and validation.

## 🏢 Organizations

### [tettyrs-org](https://github.com/tettyrs-org)
**Organizational Projects** - Core services and engines

- **[ocr-engine](https://github.com/tettyrs-org/ocr-engine)** - Python OCR service for document processing
  - JPG/PNG/PDF to text conversion
  - Bounding box and confidence scores
  - FastAPI + OpenCV + Tesseract
  
- **[ms-ocr](https://github.com/tettyrs-org/ms-ocr)** - Java correction engine
  - OCR output validation and normalization
  - Multi-format field correction
  - Indonesian locale support

- **[ocr-api](https://github.com/tettyrs-org/ocr-api)** - Document processing REST API
  - Quarkus 3.9.4 with PostgreSQL 18
  - Async OCR extraction + LLM classification
  - JWT authentication (HMAC-SHA256)
  - File upload to MinIO S3
  - Comprehensive audit logging
  - Complete with unit tests and migrations
